      How LLM-GC works

      Every request your app makes carries the whole conversation, so it grows with every message. LLM-GC sits in between and keeps it from growing without limit, while showing you exactly what the model can still see.

      What happens to a message

      1. Recent messages go to the model word for word.
      2. LLM-GC rates every older message for relevance. Once enough low-rated ones build up, it condenses them in one clean-up into a single condensed block at the start of the prompt: important messages quoted whole, routine ones summarised, cold ones reduced to facts like database: postgres.
      3. The condensed block carries only a few facts. A message whose facts did not make it is out of view: stored, but the model cannot see it. That is what to watch for.
      4. Run GC now does a clean-up immediately instead of waiting, and tells you what changed, or why nothing did.
